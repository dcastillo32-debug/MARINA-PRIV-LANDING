# Marina Privé · Partner landing

Static landing page for partners, served by Netlify at https://marinaprive.com.

- `index.html` — the page (EN / ES / AR), partner form handled by Netlify Forms (`partners`).
- `assets/` — logo, favicon and the email-signature logo (`assets/logo-firma.png`).

Every push to `main` is published automatically by Netlify.
